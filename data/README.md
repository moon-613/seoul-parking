```
data/
├── raw/                     API로 받은 원본 (가공 전)
│   ├── living_population/   생활인구 56일치
│   └── parking_seoul.csv    공영주차장
├── external/                외부에서 받은 참조 데이터
```

## 3-1. `interim/parking_geocoded.csv` — 지오코딩된 주차장 ✅

원본 `parking_seoul.csv` + SGIS 지오코딩 결과 컬럼.

| 컬럼 | 의미 |
|---|---|
| `geo_adm_cd` | **행정동코드** — SGIS 경계 `adm_cd`와 동일 체계 |
| `geo_adm_nm` / `geo_sgg_nm` | 행정동명 / 자치구명 |
| `geo_x` / `geo_y` | 경도 / 위도 (WGS84) |
| `geo_level` | 정밀도 — `0`=지번 정확, `1`=군더더기 제거, `2`=동 단위 근사 |

**결과**

| 지표 | 값 |
|---|---|
| 지오코딩 성공 | 2,185/2,189 (**99.8%**) |
| 경계코드 일치 | 2,185/2,185 (**100%**) |
| **주차면 확보** | 60,776/61,035 (**99.6%**) |
| 주차장 있는 행정동 | 325개 / 426개 |

**품질 검증**: 원래 좌표가 있던 1,456건에 대해 원본 좌표와 지오코딩 좌표를 비교한 결과
**중앙값 편차 0.103km** — 지오코딩이 정확합니다.

> 💡 행정동 배정은 `geo_adm_cd`를 **단일 기준**으로 씁니다.
> 원본 좌표 공간조인과 섞지 않는 이유: 좌표가 없는 건이 33.5%라 두 방식을 섞으면
> 기준이 달라지고, `geo_adm_cd`는 경계와 100% 일치하기 때문입니다.

실패 4건(약 259면)은 폐지 지번 등으로 조회 불가 — 전체의 0.4%.

재실행:

```powershell
.\.venv\Scripts\python.exe -m src.preprocess.geocode_parking --retry-failed  # 실패분만
```

## 4. 행정동코드 크로스워크 ✅ 해결됨

생활인구와 SGIS 경계는 코드 체계가 **다릅니다.**

| 출처 | 사직동 코드 |
|---|---|
| 생활인구 `ADSTRD_CODE_SE` | `11110530` (행정안전부 체계) |
| SGIS 경계 `adm_cd` | `11010530` (SGIS 자체 체계) |

직접 조인하면 424개 중 32개만 맞습니다.

**해결**: 서울 열린데이터광장의 **'전국 행정동 코드정보'** 가 다리 역할을 합니다.

```
생활인구 코드 → ADMI_CD → FULL_NM → SGIS adm_nm → 경계
```

**`external/adm_code/SEOUL_ADMI/ADMI_*.csv`** (43개월분)

| 컬럼 | 의미 |
|---|---|
| `ADMI_CD` | 행정동코드 — **생활인구와 같은 체계** |
| `FULL_NM` | 풀네임 — **SGIS `adm_nm`과 같은 형식** |
| `SIDO_NM` / `SGG_NM` / `ADMI_NM` | 시도 / 자치구 / 동명 |

**`external/dong_crosswalk.csv`** — 위 과정으로 생성한 최종 매핑표 (426행)

| 컬럼 | 의미 |
|---|---|
| `adm_cd` | SGIS 경계코드 |
| `admi_cd` | 생활인구 코드 |
| `adm_nm` / `sgg_nm` / `admi_nm` | 풀네임 / 자치구 / 동명 |

### 처리한 예외 3가지

| 문제 | 예시 | 처리 |
|---|---|---|
| 가운뎃점 표기 차이 | 매핑표 `상계3.4동` vs SGIS `상계3·4동` | `normalize_dong_name()` 정규화 |
| 구버전 코드 | 강북구 번1동: 생활인구 `11305590` vs 매핑표 `11305595` | 자치구 내 정렬 순서로 1:1 매칭 (7개) |
| 동 분할 (1:2) | 생활인구 `11740520`(구 상일동) = 경계 상일1동 + 상일2동 | `SPLIT_DONGS`로 명시, 경계를 dissolve |

**최종 결과: 생활인구 100% 조인, 인구 손실 0명**

> 통폐합으로 특정 월에만 존재하는 코드(용신동, 일원2동)가 있어
> **43개월 파일을 전부 병합**해 조회합니다.

생성 명령:
```powershell
.\.venv\Scripts\python.exe -m src.preprocess.dong_code
```

## 5-1. `processed/panel.csv` — 분석용 패널 ✅

**11,872행 × 21열** = 행정동 424개 × 요일 7 × 시간대 4

| 컬럼 | 의미 | 시간에 따라 변함 |
|---|---|---|
| `adm_cd` / `admi_cd` | SGIS 코드 / 행안부 코드 | — |
| `adm_nm` / `sgg_nm` / `admi_nm` | 풀네임 / 자치구 / 동명 | — |
| `weekday` / `is_weekend` / `timeslot` | 패널 키 | — |
| **`living_pop`** | 평균 생활인구 | ✅ |
| `young_pop` / **`young_ratio`** | 20~30대 수 / 비중 | ✅ |
| **`parking_slots`** | **공영**주차면수 | ❌ 고정 |
| `parking_lots` | 주차장 개소 | ❌ 고정 |
| `source` | 공급 출처 (`standard`/`seoul_api`/`none`) | ❌ 고정 |
| `avg_fee_per_hour` | 시간당 평균 요금(원) | ❌ 고정 |
| `store_food` / `store_cafe` | 음식점 / 카페 점포수 | ❌ 고정 |
| `facility_cnt` | 집객시설 수 | ❌ 고정 |
| `resident_pop` / `worker_pop` | 상주인구 / 직장인구 | ❌ 고정 |
| **`slots_per_1k`** | **1,000명당 주차면수** | ✅ (분모가 생활인구) |
| `has_parking` | 주차장 보유 여부 | ❌ 고정 |

> 💡 **시간에 따라 변하는 건 생활인구뿐입니다.** 주차·상권은 정적이라,
> `slots_per_1k`처럼 생활인구를 분모로 쓰는 변수만 요일·시간대에 반응합니다.

**예시 (사직동)**

| 요일 | 시간대 | 생활인구 | 주차면 | 1,000명당 |
|---|---|---|---|---|
| 금 | 점심 | 43,131 | 1,306 | 30.3 |
| 금 | 저녁밤 | 21,927 | 1,306 | **59.6** |

같은 주차면수인데 사람이 절반이라 체감 여유는 2배입니다.

### 공영주차 공급의 출처 (2종 병합)

표준데이터를 기본으로 쓰고, **표준데이터에 0면인 행정동에만** 서울시 API로 보충합니다.
겹치는 동이 없어 **이중 계산이 발생하지 않습니다.**

| 출처 | 동수 | 비고 |
|---|---|---|
| `standard` | 315개 | 전국주차장 표준데이터 (거주지우선 제외) |
| `seoul_api` | 43개 | 서울시 공영주차장 API (거주자우선·버스전용 제외) |
| `none` | **66개** | 양쪽 모두 0면 |
| **합계** | **358개 / 78,267면** | |

보충으로 복구된 주요 지역: 성수1가2동(329면) · 왕십리도선동(260면) · 성수2가3동(194면)

### ⚠️ 측정 대상은 "전체 주차"가 아니라 "공영주차"입니다

민영·부설주차장은 공개 데이터로 확보할 수 없습니다. 따라서:

- `parking_slots`는 **공영주차면수**입니다. 전체 주차 공급이 아닙니다.
- 0면 동 66개는 결측이 아니라 **공영주차장이 실제로 없는 동**입니다.
- **"주차난"으로 해석하면 안 됩니다.** "공영주차 인프라 부족"으로 한정 해석하고,
  분석·시각화에서 `has_parking`으로 구분하세요.

### 결측 현황

| 컬럼 | 결측 | 사유 |
|---|---|---|
| `avg_fee_per_hour` | 66개 동 + 요금 산출불가 | 공영주차장 없는 동 포함 |
| `worker_pop` | 280행 (10개 동) | 상권 직장인구 데이터가 414개 동만 제공 |
| `store_food` 등 | 28행 (1개 동) | 상권 데이터에 없는 동 |
