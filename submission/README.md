# 제출물

서울시 생활인구 기반 행정동별 주차수급 불균형 진단 및 취약지역 도출

## 폴더 구성

| 폴더 | 담을 것 | 상태 |
|---|---|---|
| `01_보고서/` | 최종 분석 보고서 (PDF/DOCX). 초안은 `reports/report.md`에서 작성 후 export | ⬜ |
| `02_발표자료/` | 발표용 슬라이드 (PPTX/PDF) | ⬜ |
| `03_최종데이터/` | 최종 분석 테이블 (`panel.csv`, `dong_summary.csv`) | ⬜ |
| `04_스크린샷/` | 대시보드 캡처 이미지 (발표자료·보고서 삽입용) | ⬜ |

## 제출 체크리스트

- [ ] 보고서 — 배경/데이터/방법론/결과/결론
- [ ] 발표자료
- [ ] 최종 데이터셋 (`panel.csv`)
- [ ] 대시보드 스크린샷 (KPI / 시간대별 곡선 / 자치구별 막대 / 지도 / PCA 군집)
- [ ] 소스코드 (GitHub 저장소 링크 또는 압축본)
- [ ] README (실행 방법 포함)

## 주의

- ⚠️ **`.env` 파일은 절대 포함하지 말 것** (API 키 유출). 제출 시 `.env.example`만 포함.
- 최종 데이터가 크면 원본 대신 집계본만 포함하고, 원본은 재현 스크립트로 대체.
