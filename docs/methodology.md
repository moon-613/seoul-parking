# 분석 방법론

회귀 잔차로 공영주차 과부족을 진단하는 방법과 그 근거.
보고서 방법론 섹션의 초안이자, 질의응답 대비 자료.

---

## 1. 회귀 잔차란

**잔차 = 실제값 − 기대값**

키·몸무게로 비유하면:

```
키 175cm인 사람  →  보통 70kg쯤 (기대값)
실제로 55kg      →  잔차 −15kg (기대보다 마름)
```

이 프로젝트:

```
생활인구 4.4만 명 오는 동네  →  공영주차 186면쯤 (기대값)
논현2동 실제                 →  13면 → 크게 부족
```

**왜 `1,000명당 주차면`만 보지 않는가**
그 지표만 쓰면 작은 동네가 유리해집니다. 사람 5천 명에 500면이면 100면/천명으로 1등이지만, 애초에 갈 이유가 없는 동네일 수 있습니다.
회귀는 **동네 규모를 감안한 뒤** 비교합니다.

---

## 2. 기대값이 나오는 과정

### 1단계 — 회귀선 긋기

358개 행정동의 점을 찍고, 모든 점에서 선까지의 **세로 거리 제곱합이 최소**가 되는 선을 찾습니다(최소제곱법).

```
log(주차면+1) = -1.1303 + 0.5950 × log(생활인구+1)
```

기준 시점은 **토요일 오후**, 공영주차 0면인 66개 동은 제외했습니다.

### 2단계 — 선에 대입 = 기대값

논현2동 예시:

| 단계 | 값 |
|---|---|
| 생활인구 | 43,855명 |
| log 변환 | 10.6887 |
| 선에 대입 | −1.1303 + 0.5950 × 10.6887 = **5.2297** |
| 원래 단위로 | exp(5.2297) − 1 = **186면** ← 기대값 |
| 실제 | **13면** |

> 186면은 외부 기준표가 아니라 **358개 동네가 만든 평균 관계**에서 나온 값입니다.

### 3단계 — 표준화 잔차

```
잔차(로그)   = 2.6391 − 5.2297 = −2.5906
잔차 표준편차 = 1.1563
표준화 잔차   = −2.5906 / 1.1563 = −2.24
```

표준편차로 나누는 이유: 동네마다 규모가 달라 원래 단위로는 비교가 안 됩니다.
"평균에서 표준편차 몇 배 떨어졌나"로 환산해야 큰 동네·작은 동네를 함께 볼 수 있습니다.

**판정 기준** (`config.yaml`)

| 표준화 잔차 | 판정 | 동수 |
|---|---|---|
| ≤ −1 | 공급 부족 | 56개 |
| −1 ~ +1 | 보통 | 248개 |
| ≥ +1 | 공급 여유 | 54개 |

## 3. 왜 로그 변환을 했는가

원단위(면수 ~ 생활인구)로 돌리면 **회귀 가정이 깨집니다.**

| 진단 | 원단위 | **로그-로그** |
|---|---|---|
| 잔차 왜도 | +2.36 ❌ | **−0.68** ✅ |
| 정규성 (Shapiro) | 위배 ❌ | 위배 (n=358로 완화) |
| 등분산 (Levene) | 위배 (p=0.002) ❌ | **양호 (p=0.45)** ✅ |
| R² | 0.135 | 0.074 |

원단위는 **큰 동네일수록 잔차가 커져** 대형 상권이 하위권을 독식했습니다.

```
원단위 하위 5 : 서교동, 여의동, 서초3동, 잠실3동, 신촌동   ← 전부 대형 상권
로그   하위 5 : 성내1동, 방배3동, 묵2동, 정릉3동, 자양3동   ← 규모 보정됨
```

로그를 쓰면 해석도 **"기대 대비 몇 배"** 가 되어 규모가 다른 동네를 공정하게 비교할 수 있습니다.
**R²가 낮아지는 것을 감수하고 가정을 지키는 선택**을 했습니다.

---

## 4. R² = 0.074를 어떻게 볼 것인가

### 계산

```
SS_tot = 515.3   실제값이 '전체 평균선'에서 흩어진 정도
SS_res = 477.3   실제값이 '회귀선'에서 흩어진 정도

R² = 1 − 477.3/515.3 = 0.074
```

**의미**: 평균 대신 회귀선을 써도 흩어짐이 **7.4%밖에 줄지 않습니다.**
= 생활인구를 알아도 그 동네 주차면 맞히기가 7.4%밖에 나아지지 않습니다.

변수를 5개로 늘려도 **0.092**에 그치고, VIF는 모두 10 미만이라 다중공선성 탓도 아닙니다.

### 예상되는 반론과 답변

> **"R²가 이렇게 낮은데 잔차 분석이 의미가 있나요?"**

**답변 1 — 목적이 예측이 아닙니다.**
"이 동네 주차면을 맞혀보자"가 아니라 **"평균적 관계에서 얼마나 벗어났나"** 를 찾는 것입니다.
예측 정확도가 낮은 것과 편차를 식별하는 것은 다른 문제입니다.

**답변 2 — 기대값 자체는 안정적입니다.**

```
논현2동 기대 주차면 186면
95% 신뢰구간       151면 ~ 228면
실제                13면   ← 구간에서 한참 벗어남
```

R²가 낮다 = **개별 동네를 정확히 맞히지 못한다**(예측 성능)
신뢰구간이 좁다 = **평균 관계선 자체는 안정적이다**(추정 신뢰도)

이 둘은 다른 이야기이며, 우리가 쓰는 건 후자입니다.

**답변 3 — 낮은 R² 자체가 결론입니다.**

> 서울 공영주차장은 사람이 얼마나 오는지와 **거의 무관하게 배치**돼 있습니다.
> 논현2동은 4.4만 명에 13면, 도봉1동은 1.75만 명에 1,413면입니다.

설명되지 않는 편차가 크다는 뜻이므로, **잔차 진단은 오히려 의미를 갖습니다.**

## 5. 교란 요인 검증 — "주거지라서 그런 것 아닌가"

**제기된 의문**: 주거지는 부설주차장(건물 주차장)이 있어 공영이 적어도 문제가 없다.
그렇다면 잔차는 "주차난"이 아니라 "주거지 여부"를 재고 있는 것 아닌가?

### 검증 결과

| 관계 | 상관계수 | 판정 |
|---|---|---|
| 주거지수 ↔ **표준화 잔차** | r = **−0.063** (p=0.24) | **무관** ✅ |
| 주거지수 ↔ 공영주차면(절대량) | r = −0.262 (p<0.001) | 유의 |

> 주거지수 = 상주인구 / (상주인구 + 직장인구). 1에 가까울수록 주거지.

**주거지일수록 공영주차가 적은 것은 사실**이지만(r=−0.26),
회귀가 생활인구로 이미 보정하고 있어 **잔차 단계에서는 상쇄**됩니다(r=−0.06).
→ 잔차 순위가 주거 성격 때문에 왜곡되지는 않습니다.

### 등급별 성격

| 등급 | 동수 | 주거지수 | 직장인구 | 음식점 |
|---|---|---|---|---|
| 공급부족 | 56 | 0.82 | 7,562 | 283 |
| 보통 | 248 | 0.80 | 10,536 | 289 |
| 공급여유 | 54 | 0.71 | 16,293 | 386 |

### 다만 — 공급부족 56개 동은 성격이 섞여 있습니다

| 유형 | 사례 | 해석 |
|---|---|---|
| **주거지** | 정릉3동(0.98) · 대학동(0.98) · 자양3동(0.94) · 묵2동(0.93) | 거주자는 부설주차장 이용 가능 |
| **업무·상권** | 논현2동(0.26) · 방배3동(0.54) · 성내1동(0.60) | 주거지 가설로 설명 안 됨 |
| **관광·대학** | 혜화동(0.78) · 이화동(0.81) | 외부 방문객 많은데 공영주차 극소 |

논현2동은 직장인구가 서울 평균의 **5.62배**, 음식점 **3.28배**로 주거지가 아닙니다
(주거지수 0.26, 414개 중 396위).

**시사점**: 같은 "공급부족"이라도 성격이 다릅니다.
**방문객 대상 추천에서는 주거지수를 함께 봐야** "주거지라 그런 것"과 "진짜 방문객 주차난"을 구분할 수 있습니다.
